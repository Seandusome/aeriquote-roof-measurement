# Tomorrow's simple desktop checklist

Use only the recovery QA account and fictional jobs. Refresh the recovery application first; sign in if prompted. Phone testing can wait.

- [ ] **Two editors:** Open the same saved QA job in two tabs and select Edit in both. Change each one differently. Save the first. The second should warn that the estimate changed, keep its unsaved work and avoid overwriting the first.
- [ ] **Original tab still works:** Make an unsaved change in one tab and wait for “Recovery copy saved.” Open another tab and Restore it. Return to the original, make a further change and select Create. Its latest work should save successfully.
- [ ] **Check the result:** Reopen the saved estimate and compare customer details, Area/Linear quantities, rates, taxes and total with Single and Expanded PDFs.

Do not use production or real customer jobs. Report any unexpected warning or mismatch; do not keep retrying a failing action.
