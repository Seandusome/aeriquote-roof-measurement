## Small restored workflow
For Snow, Pressure, Paving, Landscaping and Commercial: CORRECT AREA 1/2/etc or CORRECT LINEAR MEASUREMENT opens the selected draft on the existing Estimate aerial. No workspace navigation, no independent image-only tracing, no measurement engine replacement. Drag existing points or select REDRAW; UNDO restores the last point addition, drag or redraw action. The original workspace remains authoritative until Save. Other saved overlays/labels are removed from the editing view to avoid duplicate dimensions; original geometry stays protected internally. Cancel restores the same original overlays without rebuilding imagery.

Existing report controls are reused beside the aerial, sticky at the bottom during correction, with a scrollable height cap and touch-sized buttons. Proposed selected quantity and complete estimate total are shown before SAVE MEASUREMENT & UPDATE ESTIMATE. Explicit Area/Linear state is independent of the last workspace tool. Map pan and double-tap zoom are disabled only for correction, restored to their previous states afterward. Pinch handler remains enabled. Single-finger native scrolling over the correction map is prevented; two-touch events remain available to Leaflet.

A short gesture in an early touch run produced an extra near-corner vertex. Map clicks now add vertices only after explicit REDRAW, never while adjusting an existing outline. Crossing/invalid outlines and overlapping/duplicate saved Areas use the existing validators. No vertices are automatically deleted or reordered.

Save applies the candidate only for existing geometry/pricing validation and the existing server save path. Existing rates, taxes, discounts, customer fields, other Areas/Line, version checking, ownership/account headers and idempotency are retained. Successful Save refreshes the report in place without a second Create step or extra report usage count. Failed Save restores the original workspace and snapshot while retaining the draft. A lost response may mean the server committed: uncertain outcomes lock draft changes and Cancel until retry confirms the same idempotent operation. A definitive rejected save can be cancelled. No new persistence table, autosave or credit behavior.

PDF download, application Print, Back and New Property actions are blocked during unfinished corrections; tab closure gets the existing unsaved-work warning. Completed reports/exporters use only confirmed geometry. Saved historical reports retain their existing read-only/EDIT MEASUREMENTS / PRICE restoration safeguard; this batch does not silently modify historical snapshots.
