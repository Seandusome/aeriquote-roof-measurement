AERIQUOTE V1 — CANADA + USA

Baseline: copied from the working ShingleXtra Roof Assessment repository.

Controlled V1 changes:
1. AeriQuote blue / black / orange interface direction.
2. AeriQuote application heading and login identity.
3. Property entry supports all U.S. states plus Canadian provinces/territories.
4. Google geocoding is restricted to the U.S. or Canada based on the selected state/province.
5. ZIP / Postal Code display supports both countries.
6. Existing dropped-pin / coordinate workflow is preserved.
7. Roof measurement, aerial panning, manual/additional roof tools and calculation logic were not intentionally changed.
